# UltraKill Yourself UI — мод интерфейса для 1.7.10

Заменяет ванильные экраны Minecraft на собственные: загрузочный экран, главное
меню, настройки, меню паузы. Всё рисуется кодом (без текстур виджетов), палитра
и поведение задаются конфигом — под техсборку.

Тулчейн: **RetroFuturaGradle** (замена устаревшего ForgeGradle 1.x для 1.7.10).

## Требования
- JDK 8 для самого мода (RFG подтянет тулчейн сам)
- **JDK 25 для демона Gradle** — плагин RFG собран под него.
  В `gradle.properties` проекта это прописано, но глобальный
  `~/.gradle/gradle.properties` имеет приоритет и может перебивать значение.
  Если сборка падает с `UnsupportedClassVersionError`, запускай так:
  ```
  ./gradlew build -Dorg.gradle.java.home="C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot"
  ```
- Интернет-доступ к `nexus.gtnewhorizons.com` и стандартным Maven/Mojang/Forge репозиториям

## Сборка и запуск
```
./gradlew build
```
```
./gradlew runClient
```

## Чёрная дыра

Рисуется кодом (`BlackHole.java`), без шейдеров и текстур — работает на любом
драйвере, который тянет 1.7.10.

Линзирование считается аналитически. Полное интегрирование геодезических (как в
CUDA-рейтрейсерах) на кадр не потянуть, но для точечного источника у
шварцшильдовской линзы есть замкнутое решение, а звёздное небо — это и есть
точки. Для звезды на угловом расстоянии `b` от сингулярности при радиусе
Эйнштейна `Te`:

```
T+ = (b + sqrt(b² + 4Te²)) / 2     основное изображение, снаружи кольца
T- = (b - sqrt(b² + 4Te²)) / 2     вторичное, зеркальное внутри кольца
усиление = |1 / (1 - (Te/T)⁴)|
```

Это один корень на звезду, и оно даёт настоящие эффекты: звёзды обтекают тень,
двоятся, и вспыхивает кольцо Эйнштейна, когда звезда проходит за дырой.

Аккреционный диск — наклонённое кольцо, затенённое value-noise турбулентностью,
с релятивистским бимингом (сторона, летящая на зрителя, ярче). Плюс почти
круглое вторичное кольцо — это свет с дальней стороны диска, загнутый над тенью.

**Падающая материя.** Отдельный набор звёзд по спирали затягивается внутрь.
Это не интегрирование орбит (либо мелкий шаг, либо накопление ошибки), а прямая
запись того, как ведёт себя распадающаяся орбита: угловая скорость растёт как
`1/r^1.5` (Кеплер), радиальный снос разгоняется как `1/r²`. Получается широкая
медленная дуга, которая на последних радиусах срывается в тугую спираль — глаз
читает это как «затягивает». По дороге орбита выпрямляется в плоскость диска
(так и ведёт себя реальная аккреция), звезда растягивается приливными силами в
штрих, краснеет от гравитационного красного смещения, вспыхивает и пропадает на
границе тени. Половины делятся относительно тени, поэтому звезда, проходящая за
дырой, действительно перекрывается ей.

Цвета диска берутся из `theme.accent` / `theme.accentAlt`, так что дыра
подстраивается под палитру сборки.

## Звук и интро

`assets/uky/sounds.json` регистрирует три события:
- `uky:intro_impact` (`low.ogg`) — удар в интро
- `uky:menu_music` (`music.ogg`) — зацикленная музыка меню
- `uky:button` (`button_sound.ogg`) — клик по кнопке

Интро играет один раз за запуск игры при первом открытии главного меню:
темнота → удар со звуком, вспышка и ударная волна → дыра раскручивается →
проявляется меню. Пропускается любым кликом или клавишей.

Загрузочный экран звук не играет: он работает до инициализации звуковой
системы Minecraft.

## Компоновка главного меню

`mainmenu.layout`:
- `left` (по умолчанию) — леттеринг сверху по центру, меню текстовой колонкой
  слева, чёрная дыра занимает правые две трети. Кнопки без панелей, цвет из
  `theme.accent`, «Выйти» — из `theme.danger`.
- `center` — всё стопкой по центру, кнопки с панелями.

`mainmenu.links` — строка ссылок под меню, по одной записи в строке:
```
Label|https://example.com
```
Клик открывает ванильное окно подтверждения перехода, затем системный браузер.

## Ассеты
- Мод не поставляет ни фон, ни логотип — только шрифт и звуки.
- `assets/uky/textures/gui/logo.png` — **опционально**. Если файла нет, и в меню,
  и на загрузочном экране рисуется текстовый леттеринг из `mainmenu.title`.
- `assets/uky/textures/gui/background.png` — нужен только при
  `effects.background=image`. Если файла нет, режим тихо откатывается на `solid`.
- Загрузочный экран смотрит в `config/uky-splash/background.png` и
  `config/uky-splash/logo.png`. По умолчанию там ничего нет и экран чисто чёрный —
  это и есть задуманный вид; картинка появится только если её туда положить.

## Конфиг
`config/uky.cfg`, категории:
- `screens` — какие ванильные экраны подменять
- `effects` — `background` (`blackhole` / `image` / `solid`), частицы, виньетка,
  зерно, scanlines, дрейф фона, звуки кнопок
- `mainmenu` — какие пункты показывать, леттеринг, подпись, футер,
  `intro` (интро с ударом), `music` и `musicVolume`
- `splash` — включён ли свой загрузочный экран, строки-подсказки
- `theme` — 7 базовых цветов `0xRRGGBB`, из них выводится вся остальная палитра

Загрузочный экран читает конфиг сам (до pre-init), поэтому файл лежит по
фиксированному пути `config/uky.cfg`.

Если загрузочный экран глючит на какой-то видеокарте — `splash.customSplash=false`,
игра вернётся к форджевому. Любая ошибка внутри нашего сплэша тоже приводит к
откату на форджевый, а не к падению игры.
