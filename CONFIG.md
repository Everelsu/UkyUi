# Конфиг

Файл: `config/uky/uky.cfg`. Обычный формат Forge. Правится текстовым редактором
при закрытой игре, либо в игре: **Настройки → Настройки модов → UltraKill Yourself
UI** (там же, где конфиги остальных модов).

Рядом в `config/uky/icons/` лежат картинки для ссылок. Если у вас остался старый
`config/uky.cfg` — он переедет сам при первом запуске, значения сохранятся.

Формат строк:

```
B:ключ=true          булево — true/false
I:ключ=200           целое
D:ключ=0.55          дробное (точка, не запятая)
S:ключ=blackhole     строка
S:ключ <             список строк — по одной на строку, между < и >
    первая
    вторая
 >
```

Комментарий над каждым ключом в самом файле — короткая версия того, что ниже.

## `screens` — что мод подменяет

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `replaceMainMenu` | true | Главное меню |
| `replaceOptions` | true | Экран настроек (подэкраны — свои) |
| `replacePauseMenu` | true | Меню паузы |
| `replaceWorldList` | true | Список миров плиткой со скриншотом места, где вышел |
| `replaceLoadingScreen` | true | Тот же скриншот как фон загрузки мира |
| `replaceDeathScreen` | true | Сцена смерти вместо ванильного экрана |

Выключил любой — на его месте ваниль. Остальное продолжает работать.

## `mods` — интерфейсы чужих модов

Секция про моды, которые мод перерисовывает под себя, если они стоят в сборке.
Каждый ключ ничего не делает, когда своего мода нет, и ни один из них не меняет
поведение — только вид.

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `restyleWaila` | true | Подсказка Waila (табличка с названием блока, на который смотришь) рисуется нашей панелью: тёмная заливка, волосяная рамка, золотой рельс слева, цвет текста из палитры |
| `restyleQuestBook` | true | В книге квестов BetterQuesting выбирается тема UKY |
| `questBookTransition` | true | Затемнение мира под книгой квестов и её появление за 0.2 с вместо возникновения между двумя кадрами |
| `questBookDim` | 0.80 | Насколько тёмным становится мир под книгой. 1 — мира не видно, 0 — не трогаем вовсе |

**Waila.** Заменяется подложка и виджет прогресса. Содержимое — целиком Waila: и
название, и всё, что дописывают туда другие моды. Цвет текста берётся из
`theme.text`, потому что серый по умолчанию рассчитан на её собственную почти
чёрную коробку.

При появлении панель ничего не прячет и не двигает: сама плашка рисуется сразу и
целиком, а анимация — только украшение поверх. Золотой рельс прочерчивается сверху
вниз, и один блик проходит по верхней кромке слева направо. Играет ровно тогда,
когда подсказка пропадала и вернулась; смена содержимого (печка загорелась и
отрастила полоску прогресса) анимацию не перезапускает.

**Полоска добычи.** Пока ломаешь блок, по нижней кромке панели идёт полоска —
сколько осталось. Ваниль показывает это трещинами, а трещины говорят «немного» и
«почти»; на модовом блоке, который выламывается сорок секунд не тем инструментом,
между этими двумя ответами почти минута. Само число клиент считает каждый тик, его
просто негде увидеть.

Рисуется на уже существующей кромке, а не отдельной строкой: подсказку меряет и
раскладывает Waila, и всё, что заняло бы высоту, растолкало бы её текст. Пока
ничего не ломаешь — не рисуется вообще.

Полоски прогресса внутри подсказки (печка топится, машина работает) тоже наши:
заливка слева направо от второго акцента к первому, яркая кромка на конце и бегущий
по залитой части блик, пока работа не закончена. Размер виджета остаётся
вайловский (32x16), иначе разъехалась бы вся раскладка подсказки.

**BetterQuesting.** Тема не картинка из ресурсов, а лист виджетов, который
рисуется в момент открытия книги — из той же палитры, что и остальное меню.
Поэтому смена `theme.accent` перекрашивает и книгу квестов тоже, а не всё
остальное кроме неё. Тема регистрируется в любом случае и видна в списке тем
самой книги (**Themes**); ключ решает только, выбирается ли она автоматически.
Выключи его, если хочешь, чтобы выбор в том списке сохранялся: пока он включён,
тема ставится заново при каждом открытии книги.

`questBookTransition` — про то, что вокруг книги, а не про то, чем она нарисована,
поэтому работает с любой выбранной темой. BetterQuesting рисует свои панели прямо
поверх живого мира, без подложки: на светлом пейзаже тёмная тема теряет половину
контраста. Затемнение вешается перед её отрисовкой, книга въезжает лёгким
масштабом, а обратно затемнение снимается уже после закрытия экрана — рисовать
сами панели на выходе неоткуда, экрана в этот момент уже нет. Силу затемнения
задаёт `questBookDim`.

Цвета узлов на карте квестов: заперт — приглушённый серый, доступен — золото,
в процессе — второй акцент, пройден — тусклый светлый, повторяемый — между двумя
акцентами. Золото достаётся именно *доступному*: на карте, в которую играли
неделю, пройденных узлов большинство, и подсвечивать ярче всего надо не их.

## `mainmenu` — главное меню

Где что оказывается на экране:

```
+-------------------------------------------------+
|                 [ логотип ]                     |
|                  T I T L E                      |  <- title
|                   tagline                       |  <- tagline
|                                                 |
|   01 Одиночная игра                             |
|   02 Сетевая игра        (чёрная дыра)          |
|   03 Настройки                                  |
|   [>] YouTube  [O] Discord                      |  <- links
|                                                 |
|  Minecraft 1.7.10                               |
|  footer                          footerRight    |
+-------------------------------------------------+
```

### Ссылки

Ровно то, ради чего чаще всего лезут в конфиг. Одна строка — одна кнопка под меню.

```
S:links <
    YouTube|https://youtube.com/@channel
    Discord|https://discord.gg/invite
    Boosty|https://boosty.to/page
 >
```

Формат: `Подпись|Адрес` и необязательное третье поле — иконка.

**Если иконку не писать**, она подбирается по адресу:

| Адрес содержит | Иконка |
|---|---|
| youtube, youtu.be | экран с треугольником |
| discord | морда Clyde |
| t.me, telegram | бумажный самолётик |
| boosty | молния |
| twitch | глиф с «подбородком» |
| patreon | круг и полоса |
| rutube, vimeo, kick, trovo | треугольник «play» |
| vk.com, reddit, matrix, guilded | облачко реплики |
| donationalerts, ko-fi, paypal, yoomoney, donate | сердце |
| github, gitlab, curseforge, modrinth | звезда |
| всё остальное | глобус |

Марки нарисованы кодом и стилизованы под интерфейс: берут цвет темы, остаются
чёткими на любом масштабе GUI и не требуют файлов.

**Задать вручную** — третьим полем одно из: `youtube`, `discord`, `telegram`,
`boosty`, `twitch`, `patreon`, `play`, `chat`, `heart`, `star`, `globe`, `spark`,
`skull`.

```
    Наш сайт|https://example.com|spark
```

**Своя картинка** — положить PNG в `config/uky/icons/` (папка создаётся сама при
первом запуске) и написать её имя:

```
    Boosty|https://boosty.to/page|boosty.png
```

Квадратная картинка, 32×32 или 64×64 достаточно. Прозрачность работает. Своя
картинка рисуется как есть, без перекраски в цвет темы — логотип должен остаться
собой. Папку можно перенести ключом `linkIconFolder` (путь от папки игры).

Если файл не найден — в лог уйдёт предупреждение, а кнопка нарисуется с
подобранной иконкой. Ссылка не пропадёт.

Длинный список сам переносится на вторую строку. Клик открывает подтверждение
(ванильное «открыть ссылку?») — это защита от подмены, оставлено намеренно.

### Остальное

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `title` | ULTRAKILL YOURSELF | Крупная надпись вверху, по буквам с линией под ней. Пусто — не рисуется |
| `tagline` | пусто | Маленькая строка прямо под ней — подзаголовок сборки. Пусто — не рисуется, всё ниже поднимается |
| `footer` | пусто | Маленькая строка в **левом** нижнем углу, под «Minecraft 1.7.10». Пусто — скрыта |
| `footerRight` | UltraKill Yourself UI %version% | Маленькая строка в **правом** нижнем углу. `%version%` подставляет версию мода. Сюда обычно пишут имя и версию сборки. Пусто — скрыта |
| `layout` | left | `left` — меню колонкой слева, дыра справа. `center` — всё по центру |
| `showSingleplayer` | true | Показывать пункт «Одиночная игра» |
| `showMultiplayer` | true | Показывать «Сетевая игра» |
| `showModList` | true | Показывать «Моды» |
| `intro` | true | Интро при первом открытии меню за запуск (клик или клавиша пропускают) |
| `music` | true | Зациклить трек меню |
| `musicVolume` | 0.55 | Громкость трека поверх ползунка музыки в игре |
| `linkIconFolder` | config/uky/icons | Откуда берутся картинки ссылок |

## `splash` — экран загрузки модов

Это экран с полосой прогресса **при запуске игры**, до главного меню. Не путать с
загрузкой мира.

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `customSplash` | true | Свой экран вместо форджевого. Выключить, если на вашей видеокарте он мажет |
| `showTips` | true | Показывать строки внизу этого экрана |
| `tips` | 5 строк | Сами строки |

`tips` — это подсказки внизу экрана загрузки, по одной за раз, смена каждые 4.5
секунды по кругу в том порядке, в котором записаны. Обычный текст, без цветовых
кодов. Пишите что угодно: управление, предупреждения, ссылку на вики, шутку.

```
S:tips <
    Не копай прямо вниз.
    В сборке 300 модов. Дай ей минуту.
    F3+G показывает границы чанков.
 >
```

Чтобы не показывать ничего — `showTips=false` (список при этом сохранится) либо
удалить все строки.

## `death` — сцена смерти

Кнопок на ней нет: экран гаснет, идёт сцена, потом любая клавиша или клик
возвращают в игру. Не нажал ничего — вернёт само. Выход не мгновенный: плёнку
рвёт, текст разваливается, картинка схлопывается в полоску и гаснет.

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `sceneSeconds` | 3.0 | Сколько секунд идёт сцена, прежде чем экран начнёт слушать клавиши |
| `autoRespawn` | true | Возрождать само, если игрок ничего не нажал |
| `autoRespawnSeconds` | 6.5 | Через сколько секунд после смерти. Меньше `sceneSeconds` — сразу по концу сцены |
| `intensity` | 1.0 | Сила VHS: сканлайны, полоса, разрывы, зерно, распад заголовка. `0` — только затемнение и текст, `2` — вдвое сильнее |
| `sounds` | true | Сердцебиение и дыхание |
| `volume` | 0.85 | Их громкость поверх общего ползунка |

В хардкоре возрождать некуда: `autoRespawn` игнорируется, любая клавиша выходит
в меню.

Причина смерти определяется на клиенте по состоянию игрока (пустота, взрыв рядом,
огонь, вода, падение, моб) — от неё зависят цвет сцены, вес звуков и фраза.
Фразы лежат в `assets/uky/lang/`, ключи `uky.death.<причина>.<номер>`.

## `effects` — фон и оформление

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `background` | blackhole | `blackhole` — чёрная дыра кодом. `image` — картинка `assets/uky/textures/gui/background.png` из ресурспака. `solid` — заливка цветом темы |
| `ambientParticles` | true | Пыль и угли на фоне (только не в режиме дыры) |
| `ambientParticleBudget` | 40 | Сколько их максимум. Меньше — дешевле |
| `vignette` | true | Затемнение по краям |
| `filmGrain` | true | Зерно поверх фона |
| `scanlines` | false | Горизонтальные полосы как на ЭЛТ |
| `backgroundDrift` | true | Медленный наезд и панорама по фоновой картинке |
| `buttonSounds` | true | Звук клика по кнопке |
| `blackHoleQuality` | 200 | Шагов луча на пиксель. Ниже 200 фотонное кольцо не собирается, поэтому 200 — низ диапазона. 320 — эталон |
| `blackHoleResolution` | 150 | В процентах от окна. 100 — нативно, 150–200 — сглаживание с запасом, цена растёт примерно как квадрат |

**Если меню тормозит** — сначала снижай `blackHoleResolution`, потом
`blackHoleQuality`. Первое стоит квадрат, второе — линию.

## `theme` — палитра

Все цвета в виде `0xRRGGBB`. Опечатка не ломает игру — берётся значение по
умолчанию.

| Ключ | По умолчанию | Где видно |
|---|---|---|
| `background` | 0x0B0B0E | Фон всего |
| `surface` | 0x14141A | Заливка панелей и кнопок |
| `accent` | 0xC8A24B | Главный акцент: наведение, рейка, прогресс |
| `accentAlt` | 0x8C5A2B | Второй акцент: градиенты, угли |
| `text` | 0xE6E2D8 | Основной текст |
| `textDim` | 0x8A8578 | Приглушённый текст |
| `danger` | 0xB4472F | Опасное: выход, отключиться, удалить |
| `blackHoleHot` | 0xFFF3E4 | Внутренняя часть диска дыры |
| `blackHoleMid` | 0xC8A24B | Середина диска |
| `blackHoleCold` | 0x8C5A2B | Внешняя часть диска |

Остальное (наведения, рамки, тени, разделители) считается из этих семи, так что
одна смена `accent` перекрашивает интерфейс целиком и согласованно.
